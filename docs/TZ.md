# Техническое задание: интернет-магазин часов maison.uz

Версия от 2026-10-11. Источник требований — переписка с заказчиком ([CLIENT.md](CLIENT.md)).
План работ — [ROADMAP.md](ROADMAP.md), архитектурные решения — [DECISIONS.md](DECISIONS.md).

## 1. О проекте

**Maison** (maison.uz) — интернет-магазин часов премиум-сегмента.

- **Аудитория:** Узбекистан + покупатели из других стран (сайт для «всемирной торговли»).
- **Ассортимент:** в основном часы, новые и с историей (б/у). Модель данных допускает ремешки и аксессуары.
- **Наличие:** часть товара в наличии, часть привозится под заказ (вероятно, из Дубая) со сроком поставки.
- **Учёт остатков:** сейчас не ведётся нигде — админка сайта становится источником правды.
- **Юрлицо:** ЯТТ / компании пока нет → онлайн-оплату подключить нельзя, оплата через менеджера.
- **Фирменный стиль:** чёрный и золотой. Логотипа нет — используется текстовый знак MAISON (Cormorant Garamond).
- **Референс:** [rivolishop.com](https://www.rivolishop.com) (ОАЭ) — по структуре и функциям, не по брендингу.

## 2. Языки и валюты

- Языки: **английский** (по умолчанию, URL без префикса), **узбекский** (латиница, `/uz`), **русский** (`/ru`).
- Весь контент переводится в админке; при отсутствии перевода показывается английский.
- Базовая валюта — **USD**: все цены вводятся и хранятся только в долларах.
- Покупатель выбирает валюту отображения: USD, UZS, EUR, RUB.
- Курсы — из API ЦБ Узбекистана (cbu.uz), обновление 2 раза в день. В админке: ручной курс и наценка в %.
- Суммы в сумах округляются до тысяч.
- Заказ фиксирует валюту покупателя и курс на момент оформления.

## 3. Функциональные требования

### 3.1. Каталог
- Товар: бренд, категория, название, референс (артикул), описание, цена и зачёркнутая старая цена.
- Состояние: новые / с историей. Пол: мужские / женские / унисекс.
- Наличие: в наличии (с количеством), под заказ (срок поставки в днях), продано.
- Характеристики часов: механизм, калибр, запас хода, материал и диаметр/толщина корпуса, стекло,
  водозащита, цвет циферблата, ремешок/браслет, функции (усложнения), год, коробка, документы.
- Серийный номер — только для внутреннего учёта, на сайте не показывается.
- Справочники (материалы, цвета, стекло, функции) редактируются и переводятся в админке.
- Фильтры: бренд, состояние, наличие, пол, механизм, материал корпуса, цвет циферблата, ремешок, цена.
  Фильтры хранятся в URL (ссылкой можно поделиться). Сортировка: новинки, цена ↑/↓.
- Фото: JPG/PNG/WebP/HEIC (iPhone) до 20 МБ; автоматически создаются WebP 400/800/1600 px.

### 3.2. Заказ (без онлайн-оплаты)
- Корзина без регистрации; цены и наличие всегда пересчитываются сервером.
- Оформление: имя, телефон, email (необяз.), способ связи (Telegram / WhatsApp / звонок),
  страна, город, адрес (необяз.), способ доставки, комментарий.
- После заказа — страница со статусом по секретной ссылке и кнопками «Написать менеджеру».
- Менеджер связывается с покупателем, подтверждает заказ и согласует оплату вручную.
- Последний экземпляр резервируется при заказе (одни часы нельзя продать дважды).
- Статусы: новый → подтверждён → оплачен → отправлен → выполнен; отмена — до отправки,
  при отмене товар возвращается на склад. Заказы не удаляются.

### 3.3. Доставка
- Способы доставки — справочник в админке (названия на 3 языках, цена или «рассчитывает менеджер»).
- Для Узбекистана: самовывоз в Ташкенте, курьер по Ташкенту, BTS по Узбекистану.
- В другие страны: **BTS** (подтверждено заказчиком). Стоимость рассчитывает менеджер.
- Менеджер вписывает стоимость доставки в заказ — итог пересчитывается.

### 3.4. Уведомления
- Новый заказ → сообщение менеджеру в Telegram (состав, сумма в USD и валюте покупателя, контакты,
  ссылка на заказ в админке).

### 3.5. Админка (Django Admin + Unfold)
- Интерфейс на русском / узбекском / английском (по языку браузера).
- Разделы: Каталог (товары, бренды, категории, справочник характеристик), Продажи (заказы со счётчиком
  новых), Настройки (способы доставки, курсы валют), Пользователи и доступ.
- Перевод полей — вкладками EN / RU / UZ.

### 3.6. Запланировано до запуска (см. ROADMAP)
- Конструктор главной: баннеры, карусели товаров, карусель брендов, «Для него / Для неё», блок доверия.
- Мега-меню, страницы брендов, подвал с контактами и соцсетями.
- Информационные страницы (о нас, доставка и оплата, гарантия, возврат, конфиденциальность, условия), FAQ.
- Поиск, отслеживание заказа по номеру и телефону, полноэкранная галерея, похожие товары.
- SEO: sitemap.xml, robots.txt, разметка Product, Open Graph.
- Личный кабинет: вход через Telegram, история заказов, адреса, избранное. Гостевой заказ остаётся.
- Аналитика и уведомление о cookie.

### 3.7. После запуска
Онлайн-оплата (Payme, Click, Uzum, международные карты) и рассрочка (Uzum Nasiya, Alif) — после ЯТТ;
промокоды и раздел «Акции»; вход по SMS (Eskiz.uz); API BTS (стоимость, трек-номер); рассылка.

### 3.8. Вне рамок проекта
Арабский язык, программа лояльности, собственные бренды. Другие категории (ювелирка, ручки)
и поиск бутиков — только по отдельному подтверждению заказчика.

## 4. Нефункциональные требования

- **SEO:** серверный рендеринг, `hreflang` для трёх языков, человекочитаемые URL, мета-теги.
- **Скорость:** WebP-фото через `srcset`, кэш курсов, CDN для медиа в продакшене.
- **Безопасность:** honeypot и лимит 10 заказов/час с IP, токен-ссылки на заказы, секреты в `.env`,
  HTTPS и HSTS в продакшене.
- **Надёжность:** транзакции и блокировка строк при заказе, повтор фоновых задач при сбоях.
- **Качество:** тесты (pytest), ruff, mypy, ESLint, vue-tsc, CI на каждый push.
- **Мобильная версия:** обязательна, фильтры — в выезжающей панели.

## 5. Сроки

Первоначальная оценка для заказчика — 4–5 недель до запуска первой версии.
