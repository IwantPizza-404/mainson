# План разработки maison.uz

Оценки — рабочие дни (разработка с ИИ-ассистентом). Статус на 2026-10-11.

## Сделано

- Каркас: Nuxt 4 + Nuxt UI, Django 5.2 + Unfold, PostgreSQL, Redis, Celery, CI
- Каталог: часы с характеристиками, бренды, категории, справочники, фильтры, сортировка
- Карточка товара, WebP-миниатюры фото (включая HEIC с iPhone)
- 3 языка (en / uz / ru), 4 валюты по курсу ЦБ Узбекистана
- Корзина, оформление заказа без регистрации, страница статуса заказа
- Резерв остатков, статусы заказа, способы доставки (самовывоз, курьер, BTS)
- Уведомления менеджеру в Telegram, защита от спама
- Конструктор главной (слайдер, карусели, бренды, плитки, баннер, блок преимуществ), настройки сайта в админке
- Мега-меню, страница брендов и страница бренда, подвал с контактами и соцсетями, строка объявления
- Информационные страницы и FAQ в админке (черновики созданы, ждут текстов заказчика), страница контактов
- Поиск с опечатками (Meilisearch), отслеживание заказа, полноэкранная галерея, похожие товары
- SEO: sitemap.xml, robots.txt (на тестовом сервере индексация закрыта), разметка Product / FAQPage / Store

## Не делаем

Арабский язык, программа лояльности, собственные бренды (специфика rivolishop);
другие категории товаров (ювелирка, ручки) и поиск бутиков на карте — только если подтвердит заказчик.
