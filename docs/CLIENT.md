## Ответы заказчика (2026-10-11)

| Вопрос | Ответ | Что из этого следует |
|---|---|---|
| Пример сайта | rivolishop.com | Референс по структуре и функциям |
| Где ведёте учёт остатков? | «Нигде, у меня не все товары в наличии» | Админка — источник правды; статусы «в наличии / под заказ» |
| Магазин нацелен на узбекскую аудиторию? | «Да, но сайт нужен для всемирной торговли» | Мультивалютность, 3 языка, международная доставка |
| Товар не в наличии — под заказ? | «Правильно» | Статус «под заказ» со сроком поставки |
| Компания зарегистрирована в УЗ или ОАЭ? | «Нет» | Онлайн-оплаты нет, оплата через менеджера |
| ЯТТ есть? | «Пока нету» | То же; онлайн-оплата — после регистрации |
| Как принимаете оплату сейчас? | «Через карту» (перевод) | Оплату согласует менеджер вручную |
| Языки сайта | Английский, узбекский, русский | en / uz / ru |
| Валюта | Цена в долларах; лучше, если клиент может выбрать валюту | Базовая USD + выбор валюты |
| Только часы? | «Основной часы» | Фокус на часах, модель допускает другое |
| Как общаться с клиентами по заказам? | Telegram / WhatsApp | Кнопки мессенджеров, способ связи в заказе |
| Название сайта | Maison.uz | Бренд Maison (не Maison Luxe) |
| Логотип и фирменный стиль | «Чёрный и золотой цвет» | Логотипа нет — текстовый знак MAISON |
| Доставка в другие страны | По BTS почте | Способ «BTS — доставка в другие страны» |
| Желаемый срок запуска | Спросили «сколько дней понадобится?» | Озвучено 4–5 недель |

Для заказчика: оформлять приём оплаты на личную карту рискованно (блокировки банком),
рекомендовано зарегистрировать ЯТТ — где именно, решать с юристом/бухгалтером.
